## 🚀 Projetos em destaque

### 🏢 [NexusGest — Sistema de gestão para pequenos negócios](https://github.com/bernas0610/nexusgest)

Backend de um sistema de gestão **multiempresa**, desenvolvido com Java 21, Spring Boot, PostgreSQL e Docker Compose.

- Cadastro e autenticação com **JWT**, renovação de sessões com **refresh tokens rotativos** e logout.
- **Recuperação de senha por e-mail**, com tokens de uso único e invalidação de sessões.
- **Gestão de clientes** com pesquisa, paginação, edição, ativação/desativação e isolamento de dados por negócio.
- Controle de permissões, validação, tratamento padronizado de erros e **testes automatizados com Testcontainers**.

**Stack:** `Java` · `Spring Boot` · `Spring Security` · `PostgreSQL` · `Flyway` · `Docker Compose` · `JUnit` · `Testcontainers`

📌 **Status:** em desenvolvimento — autenticação e gestão de clientes implementadas; outros módulos estão no roadmap.

### 🎙️ [Transcreve — Plataforma de transcrição de áudio](https://github.com/bernas0610/projeto_sistema_transcricao)

Aplicação para converter áudios em texto, combinando backend Java, interface web e integração com IA.

- Upload e gravação de áudio pelo navegador.
- **Processamento assíncrono**, acompanhamento de tarefas e histórico de transcrições.
- Integração com a **API do Gemini** e processamento de arquivos com **FFmpeg**.
- Persistência com PostgreSQL, autenticação e controle de acesso aos arquivos de cada usuário.

**Stack:** `Java` · `Spring Boot` · `PostgreSQL` · `JavaScript` · `Gemini API` · `FFmpeg`

📌 **Status:** em desenvolvimento.

### 🔐 [Sistema de Gestão de Usuários — Residência de Software](https://github.com/bernas0610/CRUD_RESIDENCIASOFTWAREIII)

Aplicação full-stack para gerenciamento de usuários com autenticação e interface responsiva.

- Login e cadastro com **JWT e BCrypt**.
- **Controle de acesso por papéis** (`ADMIN` e `USER`).
- CRUD de usuários com persistência em PostgreSQL.
- Frontend em HTML, CSS e JavaScript, consumindo a API REST.

**Stack:** `Java` · `Spring Boot` · `Spring Security` · `PostgreSQL` · `Flyway` · `Swagger / OpenAPI` · `JavaScript`
